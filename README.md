# QuizHub v7 – tilfeldig spørsmålsutvalg

Oppdatering av v6. Seks quiztyper og spørsmålene er beholdt.

- Velg 5, 10, 15, 20 eller alle tilgjengelige spørsmål før en quizrunde. Valg som overstiger bankens størrelse vises ikke.
- Hver runde trekker spørsmål fra valgt quiz/kategori og stokker rekkefølgen tilfeldig (Fisher–Yates). Ingen gjentakelser innen samme runde.
- I quizkveld-modus legges poengene videre til samme poengtavle.
- En ny runde trekker på nytt; spørsmål kan dukke opp igjen i senere runder.
- Påbegynte spill fra eldre versjoner med spørsmål nummer >1 kan spilles ferdig i gammel rekkefølge.
