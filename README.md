# QuizHub v18 — lettere og mer variert spørsmålsbank

- 158 nye, åpne allmennspørsmål med fasit, emnekategori og nivå (enkel/middels).
- Spørsmål om geografi og sport gjenbrukes som samme objekt i de respektive fagbankene.
- Familiequiz: 80 % enkle / 20 % middels. Vanlig quiz: 60 % enkle / 35 % middels / 5 % vanskelige. Ekspertquiz uendret.
- Ingen endringer i de seks hovedvalgene, poengtavle eller historikknøkkel.
- Spørsmål med identisk spørsmålsordlyd er filtrert bort. Noen nærliggende tema kan fremdeles finnes fra før.
- De nye spørsmålene er redaksjonelt formulert, men hele banken er ikke fullstendig eksternt faktasjekket.

## Publisering
Pakk ut filene og erstatt filene med samme navn i eksisterende GitHub-repository. Render publiserer automatisk hvis auto-deploy er aktivert.
