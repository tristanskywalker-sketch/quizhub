# QuizHub v5 – Geografi Fun Facts

Utvidet spørsmålsbank i Geografi fra 30 til 66 åpne spørsmål. Nye oppgaver handler om uvanlige grenser, flagg, øyer, rekorder, mikrostater og «nevn alle»-spørsmål. Quizens eksisterende funksjoner og de øvrige spørsmålsbankene er beholdt.

## Oppdatering
Pakk ut ZIP-filen. Last opp alle filene til **roten av eksisterende `quizhub`-repository på GitHub**, og erstatt tidligere filer. Render publiserer normalt automatisk. Ingen nye Render-innstillinger er nødvendig.

Word (.docx) kan senere lastes opp til samtalen med spørsmål og fasit, så kan innholdet bearbeides og legges inn i `general` i `data.js`.
