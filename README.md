# QuizHub v20 — kategorirydding og O’Reillys (6)

- 75 tidligere «Blandet»-spørsmål er klassifisert i konkrete emnekategorier.
- Årstallspørsmålene er i tillegg merket med spørsmålstype.
- Nye spørsmål er bearbeidet fra det siste Word-dokumentet med tidløse formuleringer og vurdert vanskelighetsgrad.
- Geografi- og sportsspørsmål blir tilgjengelige i både Allmennquiz og fagquizene, med samme objekt og spørsmålhistorikk.
- Nyhetsavhengige, svært uklare og antatt dublerte spørsmål er holdt utenfor.
- Eksisterende spilldata, spillerregistrering og menyvalgene er beholdt.

## Publisering
Pakk ut ZIP-filen og last opp alle filene til roten av det eksisterende GitHub-repositoryet `quizhub`. Commit endringene; Render kan så publisere automatisk.
