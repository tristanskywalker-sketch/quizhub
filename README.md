# QuizHub v12

Basert på v11. Lagt til **100 nye geografispørsmål**, og **22 bearbeidede spørsmål** fra `Quiz spm Oreilleys (2).docx` i Allmennquiz. Alle nye spørsmål har `difficulty` (easy/medium/hard).

Rettet også knappen **Vis neste ledetråd** i «Gjett året» som tidligere forutsatte `clues` i stedet for `yearClues`.

Spørsmål med uklar fasit, manglende bilder eller tidsavhengig informasjon er utelatt. Eksisterende quiztyper, poeng, tilfeldig trekking og nivåblandinger er beholdt.

## Oppdatering
Last opp innholdet fra denne mappen til samme `quizhub`-repository på GitHub. `index.html`, `data.js`, `app.js`, `style.css`, `sw.js`, `icon.svg`, `manifest.webmanifest` skal ligge i rotmappen. Publish Directory i Render: `.`.
