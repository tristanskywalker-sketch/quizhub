# QuizHub v17 – nye renskrevne spørsmål fra O’Reillys

- 72 nye, kvalitetssjekkede spørsmål fra vedlagte «Quiz spm Oreilleys (5).docx».
- Faste historiske datoer erstatter relative uttrykk («nylig», «i dag», «de siste sesongene»).
- Alle har emnekategori, vanskelighetsgrad og fasit.
- Geografi- og sportsspørsmålene er tilgjengelige i egne quiztyper og i Allmennquiz; det er samme objekt i begge utvalg.
- Uklare, ufullstendige og kildekrevende spørsmål er holdt utenfor.
- Hele den eldre spørsmålsbanken er ikke manuelt faktakontrollert.
- De seks quiztypene, spillerhistorikk og quizkveld er beholdt.
